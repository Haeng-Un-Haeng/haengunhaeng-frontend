# 🍀 행운행

**정류장에서 발견하는 일상의 작은 행운.**

행운행은 버스 정류장 주변에서 클로버를 수집하고, 나만의 도감에 기록하는 위치 기반 웹 서비스입니다. 익숙한 이동 경로에서 새로운 클로버를 발견하는 즐거움을 제공합니다.

## 개발 현황

현재 Next.js 기반의 초기 개발 환경을 구성한 상태이며, 실행하면 기본 시작 화면이 표시됩니다. 아래 서비스 기능은 구현 예정입니다.

## 주요 기능 · 구현 예정

- **비로그인 체험:** 가상 행운행 정류장의 클로버 1개를 통해 수집 경험을 소개합니다. 위치 권한을 허용하지 않아도 체험할 수 있습니다.
- **카카오 로그인:** 체험 모달에서 로그인을 시작하며, 첫 로그인 시 공통 클로버와 첫 칭호를 지급합니다. 칭호의 상세 설계와 구현은 추후 진행합니다.
- **지도에서 클로버 수집:** 주변 실제 정류장의 클로버를 표시하고, 수집 가능한 클로버를 클릭하면 획득 결과를 보여 줍니다.
- **클로버 도감:** 수집한 클로버를 종류별로 확인하고, 누적 수집 개수와 수집 정류장·날짜 이력을 살펴봅니다.
- **홈:** 보유한 클로버를 확인하고 지도로 이동합니다. 클로버 심기는 세부 규칙 확정 후 구현합니다.

### 수집 기준

| 항목 | 기준 |
| --- | --- |
| 수집 거리 | 현재 위치에서 정류장까지 반경 50m 이내 |
| 위치 정확도 | 브라우저의 위치 정확도 추정치 30m 이하 |
| 수집 횟수 | 사용자별·정류장별 하루 1회 |
| 일일 초기화 | 서버의 한국 시간(`Asia/Seoul`) 기준 자정 |
| 수집 완료 정류장 | 당일 지도에서 클로버 숨김, 다음 날 다시 수집 가능 |
| 로그인 후 위치 권한 거부 | 실제 위치 탐색·수집 차단 및 권한 안내 |

수집 정책은 서버에서 최종 검증합니다. 위치 정확도 기준은 실기기 테스트 결과에 따라 조정할 수 있습니다.

## 기술 스택

### 현재 구성

| 영역 | 기술 |
| --- | --- |
| 프레임워크 | Next.js 16 · App Router |
| UI | React 19 |
| 언어 | TypeScript 5 |
| 스타일 | Tailwind CSS 4 |
| 코드 검사 | ESLint 9 · eslint-config-next |
| 패키지 관리 | npm · package-lock.json |

정확한 의존성 버전은 `package.json`과 `package-lock.json`에서 관리합니다.

### 도입 예정

- 지도: MapLibre GL JS · OpenStreetMap 기반 벡터 타일 — 타일 공급자 미정
- 서버 상태 관리: TanStack Query
- 공유 UI 상태 관리: Zustand
- 코드 포맷·커밋 검사: Prettier · Husky · lint-staged
- UI 개발·문서화: Storybook · 접근성 애드온
- 테스트·API 모킹: Jest · React Testing Library · MSW

## 로컬 실행

### 준비 사항

- Node.js와 npm이 설치되어 있어야 합니다. 현재 설치된 Next.js의 Node.js 요구 조건은 `20.9.0 이상`입니다.
- 명령은 이 저장소의 루트, 즉 `package.json`이 있는 `frontend` 폴더에서 실행합니다.
- 이미 프로젝트가 생성되어 있으므로 `create-next-app`을 다시 실행하지 않습니다.

### 의존성 설치 및 개발 서버 실행

```bash
npm ci
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속합니다. 기본 화면은 `src/app/page.tsx`에서 수정할 수 있습니다.

### 사용 가능한 명령

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 생성 |
| `npm run start` | 빌드된 앱의 프로덕션 서버 실행 — 먼저 build 필요 |
| `npm run lint` | ESLint 코드 검사 |

테스트·Storybook·포맷 검사 명령은 해당 도구를 도입할 때 추가합니다.

## 환경변수

현재 기본 화면 실행에 필요한 별도 환경변수는 없습니다. 지도 공급자와 API 연동 설정이 확정되면 필요한 변수와 설정 방법을 추가합니다.

- 실제 로컬 설정은 `.env.local`에 저장하고 Git에 커밋하지 않습니다.
- 환경변수 도입 시 값이 비어 있거나 예시 값만 들어 있는 `.env.example`을 제공합니다. 현재 `.gitignore`는 `.env*` 전체를 제외하므로, 예제 파일을 추가할 때 `!.env.example` 예외도 함께 설정합니다.
- `NEXT_PUBLIC_` 접두사가 붙은 변수는 브라우저에 공개되므로 비밀 키를 넣지 않습니다.
