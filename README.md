# 🍀 행운행

**정류장에서 발견하는 일상의 작은 행운.**

행운행은 버스 정류장 주변에서 클로버를 수집하고, 나만의 도감에 기록하는 위치 기반 웹 서비스입니다. 익숙한 이동 경로에서 새로운 클로버를 발견하는 즐거움을 제공합니다.

## 개발 현황

**1차 목업 개발 중**입니다. 기존의 별도 홈 화면을 제거하고 **지도 자체를 홈(`/`)**으로 변경했습니다.

현재 프론트엔드에는 MapLibre 지도, 위치 권한에 따른 기준 위치 선택, 정류장 목업 데이터 조회 로직, 체험용 클로버 마커와 랜덤 클로버·행운 메시지 모달이 구현되어 있습니다. 도감(`/collection`)은 아직 기본 화면 틀만 있는 상태입니다. **카카오 로그인·백엔드·실제 수집 저장은 연결되지 않았습니다.**

다음 목업 작업에서는 클로버 마커를 누르면 **정류장 이름과 물음표 상자 3개**를 보여 주고, 상자 하나를 선택하면 클로버와 메시지가 공개되는 흐름을 구현할 예정입니다. 현재 코드는 마커 클릭 시 결과 모달을 바로 표시합니다.

## 주요 기능

### 현재 구현된 목업

- **지도(홈):** `/`에 접속하면 MapLibre 기반 지도가 표시됩니다. 별도 홈 화면은 사용하지 않습니다.
- **비로그인 체험 위치:** 위치 권한을 허용하면 현재 위치를 기준으로, 위치를 얻지 못하면 기본 위치를 기준으로 가까운 정류장을 찾는 로직이 구현되어 있습니다. 체험에는 실제 수집 거리 제한을 적용하지 않습니다.
- **체험용 클로버:** 지도에 체험용 클로버 마커를 표시하고 클릭하면 클로버와 행운 메시지를 각각 독립적으로 선택해 모달에 표시합니다. **서버 저장은 하지 않습니다.**
- **공통 UI·Storybook:** 버튼, 클로버 카드·마커, Dialog, 안내 컴포넌트 등의 공통 UI와 Storybook 설정이 구성되어 있습니다.
- **도감:** `/collection` 라우트와 화면 틀이 있으며 목록·상세 구현은 후속 작업입니다.

### 이후 구현할 기능

- **체험 모달 개선:** 마커 클릭 → 정류장 이름 표시 → 물음표 상자 3개 중 하나 선택 → 클로버·행운 메시지 공개 및 체험 획득.
- **클로버 도감:** 클로버·칭호 탭, 수집 목록, 클로버별 누적 수집 개수와 정류장·날짜·획득 당시 메시지 상세.
- **카카오 로그인:** 체험 결과에서 로그인 시작, 첫 로그인 보상 지급과 회원별 수집 이력 관리.
- **실제 정류장 수집:** 로그인 후 위치·거리·당일 수집 여부를 서버에서 검증하고 클로버를 저장.

### 실제 수집 정책 · 백엔드 연동 후 적용

| 항목                     | 기준                                              |
| ------------------------ | ------------------------------------------------- |
| 수집 거리                | 현재 위치에서 정류장까지 반경 50m 이내            |
| 위치 정확도              | 브라우저 위치 정확도 추정치 30m 이하              |
| 수집 횟수                | 사용자별·정류장별 하루 1회                        |
| 일일 초기화              | 서버의 한국 시간(`Asia/Seoul`) 기준 자정          |
| 수집 완료 정류장         | 당일 지도에서 클로버 숨김, 다음 날 다시 수집 가능 |
| 로그인 후 위치 권한 거부 | 실제 위치 탐색·수집 차단 및 권한 안내             |

위 정책은 **현재 비로그인 목업에서 적용되는 수집 제한이 아니라** 향후 서버가 최종 검증할 기준입니다. 위치 정확도 기준은 실제 기기 확인 후 조정할 수 있습니다.

## 기술 스택

### 현재 프로젝트에 구성된 기술

| 영역             | 기술                                            |
| ---------------- | ----------------------------------------------- |
| 프레임워크·UI    | Next.js 16 · App Router · React 19              |
| 언어·스타일      | TypeScript 5 · Tailwind CSS 4                   |
| 지도             | MapLibre GL JS · OpenStreetMap 기반 지도 스타일 |
| 공유 UI 상태     | Zustand 5                                       |
| 코드 품질        | ESLint 9 · Prettier 3 · eslint-config-prettier  |
| 커밋 전 검사     | Husky · lint-staged                             |
| UI 개발·문서화   | Storybook 10 · 접근성 애드온                    |
| 기존 테스트 환경 | Jest · React Testing Library · user-event       |
| 패키지 관리      | npm                                             |

정확한 의존성 버전과 스크립트는 `package.json`을 기준으로 확인합니다. **기존 테스트 환경과 테스트 파일은 유지하지만, 새로운 자동 테스트 코드 작성은 현재 구현 일정의 필수 항목이 아닙니다.** 필요한 시점에 별도로 학습하며 작성합니다. Storybook은 계속 사용합니다.

### 후속 도입·연동 예정

- **서버 데이터 관리:** TanStack Query
- **API 상태 모킹:** 필요 시 MSW를 Storybook 등 개발 환경에 연동
- **백엔드·로그인:** Spring Boot API, 데이터베이스, 카카오 로그인

## 화면 경로

| 주소          | 현재 역할                                       |
| ------------- | ----------------------------------------------- |
| `/`           | 지도 홈 (`src/app/page.tsx`에서 `MapPage` 연결) |
| `/collection` | 도감 화면 틀                                    |

기존 `/home`, `/map` 페이지 파일은 제거했습니다. 해당 주소의 호환 리다이렉트는 현재 설정하지 않았습니다.

## 로컬 실행

### 준비 사항

- Node.js와 npm을 설치합니다. 프로젝트 CI는 **Node.js 24**를 사용합니다.
- 명령은 `package.json`이 있는 프론트엔드 저장소 루트에서 실행합니다.
- 이미 생성된 프로젝트이므로 `create-next-app`을 다시 실행하지 않습니다.

### 의존성 설치 및 개발 서버 실행

`package-lock.json`이 있는 정상적인 저장소에서는 다음 명령을 사용합니다.

```bash
npm ci
npm run dev
```

**참고:** 검토용으로 전달된 ZIP에는 `package-lock.json`이 포함되어 있지 않습니다. 실제 로컬 저장소에도 이 파일이 없다면 `npm ci` 대신 `npm install`로 잠금 파일을 생성하고, 팀에서 사용하는 저장소에 함께 커밋해야 합니다. GitHub Actions의 현재 CI도 `npm ci`를 사용합니다.

브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속하면 **지도 홈(`/`)**이 열립니다.

지도에서 체험용 정류장을 표시하려면 `load-nearby-bus-stops.ts`가 요청하는 **`public/mock/bus-stops/<위도 격자>/<경도 격자>.json`** 데이터가 필요합니다. 검토용 ZIP에는 이 JSON 파일들이 없으므로 정류장이 나타나지 않을 수 있습니다. 정류장 전처리 로직은 `tooling/generate-bus-stop-fixtures.mjs`에서 확인할 수 있습니다.

### 사용 가능한 명령

| 명령                      | 설명                                      |
| ------------------------- | ----------------------------------------- |
| `npm run dev`             | 개발 서버 실행                            |
| `npm run build`           | Next.js 프로덕션 빌드                     |
| `npm run start`           | 빌드된 앱 실행 (`build` 선행)             |
| `npm run lint`            | ESLint 코드 검사                          |
| `npm run format`          | ESLint 자동 수정 및 Prettier 포맷 적용    |
| `npm run format:check`    | Prettier 포맷 검사                        |
| `npm run typecheck`       | TypeScript 타입 검사                      |
| `npm run check`           | 포맷팅 규칙·ESLint·Prettier·타입 검사     |
| `npm run verify`          | `check` 및 프로덕션 빌드                  |
| `npm run storybook`       | Storybook 개발 서버 실행 (기본 포트 6006) |
| `npm run build-storybook` | Storybook 정적 빌드                       |
| `npm test`                | 기존 Jest 테스트 실행 (별도 학습 시 활용) |

## 환경변수

현재 목업 지도 스타일 URL은 지도 코드에 설정되어 있으며 기본 화면 실행을 위한 별도 환경변수는 없습니다. 서버 API와 로그인 연동 단계에서 필요한 환경변수를 추가할 예정입니다.

- 로컬 비밀 설정은 `.env.local` 등에 보관하고 Git에 커밋하지 않습니다.
- `.env.example`을 추가할 때는 `.gitignore`의 `.env*` 규칙에 예외(`!.env.example`)를 설정합니다.
- `NEXT_PUBLIC_` 접두사가 붙은 값은 브라우저에 공개되므로 비밀 키를 넣지 않습니다.
