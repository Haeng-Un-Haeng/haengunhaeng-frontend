# 🍀 행운행

**정류장에서 발견하는 일상의 작은 행운**

행운행 — 버스 정류장 주변에서 클로버를 수집하고 나만의 도감에 기록하는 위치 기반 웹 서비스  
익숙한 이동 경로에서 새로운 클로버를 발견하는 즐거움 제공

## 개발 현황

**1차 목업 개발 중**

- **홈 구성**
  - 기존 별도 홈 화면 제거
  - 지도 자체를 홈(`/`)으로 전환
- **현재 프론트엔드 구현 범위**
  - MapLibre 지도 및 위치 권한에 따른 기준 위치 선택
  - 정류장 목업 데이터 조회 로직과 체험용 클로버 마커
  - 정류장명과 물음표 상자 3개를 보여 주는 모달 UI
- **도감**: `/collection` 기본 화면 틀 구성
- **미연동 항목**: 카카오 로그인·백엔드·실제 수집 저장
- **클로버 공개 흐름**
  - 클로버 마커 클릭 시 정류장 이름과 물음표 상자 3개 표시
  - 상자 선택 애니메이션과 목업 보상 준비가 모두 완료된 시점에 결과 공개
- **학습 기록**: `docs/learning-3-box-flow.md`에 해당 흐름의 직접 구현 및 학습 내용 기록

## 주요 기능

### 현재 구현된 목업

- **지도(홈)**
  - `/` 접속 시 MapLibre 기반 지도 표시
  - 별도 홈 화면 미사용
- **비로그인 체험 위치**
  - 위치 권한 허용 시 현재 위치를 기준으로 가까운 정류장 탐색
  - 위치 확인 실패 시 기본 위치를 기준으로 가까운 정류장 탐색
  - 체험에서는 실제 수집 거리 제한 미적용
- **체험용 클로버**
  - 지도 마커 클릭 → 정류장 이름 표시 → 상자 3개 중 하나 선택
  - 선택한 상자 중앙 이동 → 클로버·행운 메시지 공개
  - 서버 저장 없음
- **공통 UI·Storybook**
  - 버튼, 클로버 카드·마커, Dialog, 안내 컴포넌트 등의 공통 UI 구성
  - Storybook 환경 구성
  - `Pages/Map/TrialDiscoveryDialog` 스토리에서 지도 데이터 없이 체험 모달 단독 확인 가능
- **도감**
  - `/collection` 라우트 및 기본 화면 틀 구성
  - 목록·상세 기능은 후속 구현 예정

### 이후 구현할 기능

- **클로버 도감**
  - 클로버·칭호 탭과 수집 목록
  - 클로버별 누적 수집 개수
  - 정류장·날짜·획득 당시 메시지 상세
- **카카오 로그인**
  - 체험 결과에서 로그인 시작
  - 첫 로그인 보상 지급 및 회원별 수집 이력 관리
- **실제 정류장 수집**
  - 로그인 후 서버의 위치·거리·당일 수집 여부 검증
  - 검증 후 클로버 저장

### 실제 수집 정책 · 백엔드 연동 후 적용

| 항목                     | 기준                                              |
| ------------------------ | ------------------------------------------------- |
| 수집 거리                | 현재 위치에서 정류장까지 반경 50m 이내            |
| 위치 정확도              | 브라우저 위치 정확도 추정치 30m 이하              |
| 수집 횟수                | 사용자별·정류장별 하루 1회                        |
| 일일 초기화              | 서버의 한국 시간(`Asia/Seoul`) 기준 자정          |
| 수집 완료 정류장         | 당일 지도에서 클로버 숨김, 다음 날 다시 수집 가능 |
| 로그인 후 위치 권한 거부 | 실제 위치 탐색·수집 차단 및 권한 안내             |

- 위 정책은 현재 비로그인 목업의 수집 제한이 아닌 향후 서버에서 최종 검증할 기준
- 위치 정확도 기준은 실제 기기 검증 후 조정 가능

## 로컬 실행

### 준비 사항

- Node.js 및 npm 설치
- 프로젝트 CI의 **Node.js 24** 사용
- `package.json`이 위치한 프론트엔드 저장소 루트에서 명령 실행
- 기존 프로젝트 사용 시 `create-next-app` 재실행 불필요

### 의존성 설치 및 개발 서버 실행

`package-lock.json`이 있는 정상적인 저장소 기준 설치 및 실행 명령

```bash
npm ci
npm run dev
```

- 프로젝트에 `package-lock.json` 포함
- GitHub Actions에서도 `npm ci` 사용
- 브라우저에서 [http://localhost:3000](http://localhost:3000) 접속 시 지도 홈(`/`) 표시

**체험용 정류장 데이터 안내**

- 지도에서 체험용 정류장을 표시하려면 `load-nearby-bus-stops.ts`가 요청하는 `public/mock/bus-stops/<위도 격자>/<경도 격자>.json` 데이터 필요
- 현재 전달본에는 `public/` 데이터가 없어 지도에 체험용 정류장이 표시되지 않을 가능성 존재
- 데이터 조회 경로와 전처리 관련 코드는 `src/_pages/map/model/load-nearby-bus-stops.ts` 및 `tooling/` 폴더에서 확인 가능

### 사용 가능한 명령

| 명령                      | 설명                                      |
| ------------------------- | ----------------------------------------- |

## 환경변수

- 현재 목업 지도 스타일 URL은 지도 코드에 설정
- 기본 화면 실행을 위한 별도 환경변수 없음
- 서버 API 및 로그인 연동 단계에서 필요한 환경변수 추가 예정
- 로컬 비밀 설정은 `.env.local` 등에 보관하고 Git 커밋에서 제외
- `.env.example` 추가 시 `.gitignore`의 `.env*` 규칙에 예외(`!.env.example`) 설정
- `NEXT_PUBLIC_` 접두사가 붙은 값은 브라우저에 공개되므로 비밀 키 포함 금지
